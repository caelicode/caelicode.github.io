SpeakScribe

Privacy Policy

Last updated: August 28, 2026

Overview

SpeakScribe is a Chrome extension that converts speech to text. This policy explains what the extension accesses, how each transcription mode processes data, and what is stored.

Chrome Web Store Limited Use

SpeakScribe's use and transfer of information received from Google APIs complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is used only to provide or improve the transcription features the user chooses. SpeakScribe does not sell user data, use it for advertising, use it to determine creditworthiness, or allow humans to read transcript content except with the user's explicit consent for support, when necessary for security, or when legally required.

Data Collection

SpeakScribe does not include analytics, advertising, or tracking SDKs. In Chrome local storage it keeps dictation, display, export, and interface preferences; custom vocabulary and voice commands; per-site rules, including the relevant site hostnames; widget position; meeting-mode state; and install or trial timestamps. When a paid license is activated, it also keeps the full license key, device instance identifier, customer email and product name returned by Lemon Squeezy, and activation and last-validation timestamps. These records are held in the user's Chrome profile and are not separately encrypted by SpeakScribe.

During a transcription session, transcript text, line timestamps, and active-capture state are kept in Chrome's temporary session storage so extension views remain synchronized. SpeakScribe does not write that transcript state to its persistent local storage. Chrome clears session storage when the extension is reloaded or updated and when the browser restarts.

The extension does not request Chrome's browsing-history permission. Its content script is present on webpages so the widget can appear and place dictated text into the editable field selected by the user. Audio and transcript data are processed only for the selected transcription mode.

Speech Processing

Standard: Chrome's Web Speech API sends audio to Google's speech-recognition service. This browser feature is governed by Google's policies, and SpeakScribe does not control that transfer.

Local Whisper: The extension downloads a selected model from Hugging Face/Xenova and caches it in Chrome. Final transcription runs locally. If Local live preview is enabled, Chrome's Web Speech API may process interim preview words.

Enhanced and Meeting: Audio is streamed through the SpeakScribe proxy to Deepgram for real-time recognition. The proxy relays audio and transcript messages in memory and is not designed to save recordings or transcript content. Hosting infrastructure and Deepgram may process connection metadata under their own security, logging, and retention practices.

Storage and User Control

Local Whisper model files are stored separately in the browser's extension cache or IndexedDB. Deactivating a license removes its locally stored license records. Uninstalling SpeakScribe removes its extension-owned data; Chrome's extension data controls can also be used to clear stored settings, session data, and cached models.

Permissions

Content scripts on webpages: Show the dictation widget and insert text into the editable field chosen by the user. Chrome blocks content scripts on protected browser pages.

storage: Save preferences and license state locally.

tabCapture: Capture audio from a user-selected tab for Meeting transcription.

offscreen: Run Enhanced, Local Whisper, and Meeting audio work in an extension-owned background document.

License Validation

During activation, periodic validation, and deactivation, SpeakScribe sends the full license key and device instance identifier to Lemon Squeezy over HTTPS. Lemon Squeezy returns license status and account metadata such as customer email and product name, which are stored locally as described above.

At the start of each Enhanced or Meeting session, the extension also sends the full license key and device instance identifier over an encrypted WebSocket connection to the SpeakScribe proxy. The proxy validates them with Lemon Squeezy when a current result is not already cached. It keeps only a cryptographic hash of the key and instance in a bounded in-memory validation cache for up to five minutes and for concurrent-session enforcement while the session is active. License credentials are not sent to Deepgram. Browsing data, audio, and transcript content are not included in license-validation requests.

Third-Party Services

SpeakScribe uses Google/Chrome speech recognition for Standard and optional Local preview, Hugging Face/Xenova for Local model downloads, Deepgram for Enhanced and Meeting transcription, Railway to host the in-memory proxy, and Lemon Squeezy for license validation. These providers process the data needed for their stated function under their own privacy and security practices. SpeakScribe does not include advertising or tracking integrations.

Retention and Security

The proxy relays audio and transcript messages in memory and is not designed to persist recordings or transcript content. It processes a connection's IP address in memory for authentication rate limiting. Its application logs may contain a random connection identifier, language and diarization choices, connection timing, authentication outcome, rejected origin, service events and errors, and a truncated cryptographic credential hash. Audio, transcript content, and full license keys are not written to application logs by design.

Railway and the other third-party providers may retain infrastructure, network, security, and service logs according to their own policies and configured retention. Network services use encrypted HTTPS or WebSocket connections.

Children's Privacy

SpeakScribe does not knowingly collect personal information from children under 13.
